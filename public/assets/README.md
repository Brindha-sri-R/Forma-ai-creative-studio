# Asset Frames Directory

Place your image and video assets in this folder (`public/assets/`) and wire their paths inside `src/data/assets.ts`.

## Reserved Hero Fanned Frames (`1:1` / `4:5` recommended)
- `hero-01.jpg` — Far left card (Image frame)
- `hero-02.jpg` — Left-inner card (Image frame)
- `hero-03.jpg` — Center-left card (Image frame)
- `hero-04.jpg` — Center anchor card (Image frame)
- `hero-05.jpg` — Center-right card (Video / Image frame)
- `hero-06.jpg` — Right-inner card (Image frame)
- `hero-07.jpg` — Far right card (Video / Image frame)

## Reserved Curated Gallery Frames (`4:3` recommended)
- `gallery-01.jpg`
- `gallery-02.jpg`
- `gallery-03.mp4` (or `.jpg` poster)
- `gallery-04.jpg`
- `gallery-05.mp4` (or `.jpg` poster)
- `gallery-06.jpg`

Note: You can also click any empty frame or open **Asset Frames** in the top bar to preview local image/video files directly in your browser before committing static files here.
